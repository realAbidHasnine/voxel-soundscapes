# Project steps

This reference explains the numbered steps mentioned in the prompt log.
“Step 1” in `prompts/prompt_3.txt` refers to project setup below.

1. **Project setup:** Set up Vite, React, TypeScript, Tailwind, Tone.js, and AI prompt logging.
2. **Recursive tree:** Generate a configurable tree that repeats consistently for the same seed.
3. **Musical events:** Turn the tree’s branches into notes and musical timing.
4. **Initial playback:** Add basic playback controls and tune the melody, chords, and drone.
5. **Tree visuals:** Draw the tree on canvas and bloom each branch as its note plays.
6. **Shape controls:** Adjust depth, branching, spread, and tempo, and regrow with a new seed.
7. **Audio export:** Download the full soundscape as a .wav file.
8. **Presets and zen:** Three named soundscapes, plus a distraction-free view.
9. **Share and polish:** Shareable links, a level counter, and accessibility.

All steps are complete.
